Start

1. python -m venv venv
2. .\venv\scripts\Activate.ps1
3. pip install -r requirements.txt
4. py main.py
5. Create `.env` input the following

```
ACCOUNT_NUMBER=xxx
PASSWORD="xxx"
SERVER="xxx"
```
